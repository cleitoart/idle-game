## Recomendacoes para nosso projeto

### Para consultar regularmente
1. **Melvor Idle wiki** - referencia operacional pra mastery system, gathering, township.
2. **PoE Wiki (poewiki.net)** - referencia de affix tiers e atlas progression.
3. **OSRS Wiki** - padrao de qualidade; tudo claro, objetivo, com tabelas.
4. **Crusaders Lost Idols Fandom** - formacoes/auras 3x2.
5. **Grim Dawn Fandom + Grimtools** - constelacoes.

### Para checagem cruzada
- Wowhead + Wowpedia para coleções/transmog.
- Maxroll para curvas de poder e theorycraft moderno.

### Para evitar duplicacao
- Quando possivel, citar wiki **oficial** em primeiro lugar.
- Fandom como fallback se oficial nao cobre o tema.
